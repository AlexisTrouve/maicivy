================================================================================
                          UTILISATION API
================================================================================

Endpoint: GET /api/v1/cv

AVANT:
  GET /api/v1/cv?theme=fullstack

APRÈS:
  GET /api/v1/cv?theme=fullstack&lang=fr   (défaut)
  GET /api/v1/cv?theme=fullstack&lang=en
  GET /api/v1/cv?theme=backend&lang=en

Export PDF:
  GET /api/v1/cv/export?theme=backend&lang=en

Comportement:
  ├─ lang=fr (défaut): Retourne français
  ├─ lang=en: Retourne anglais
  ├─ Traduction manquante: Fallback vers français
  └─ Langue invalide: Fallback vers français

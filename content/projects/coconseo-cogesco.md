## Description

Cockpit SEO professionnel pour la planification, production et publication de cocons sémantiques à grande échelle. 43 modules spécialisés en 10 familles : stratégie de mots-clés, génération de contenu (briefs, articles, FAQs, meta descriptions), planification d'images, linking interne, scoring SEO 6 composantes, et publication directe WordPress/WooCommerce. Backend microservices Rust (Actix-web, Tokio) avec gateway HTTP, base MySQL 47 tables, agent Python autonome connecté à Claude API avec 33 outils intégrés et architecture tool-use. Import de données Google Ads, SEMrush, GSC, GA4, Amazon. Interface desktop Flutter. 62 tests E2E, 188 tests Flutter, 154 tests Rust. Déployé en production sur VPS Docker.

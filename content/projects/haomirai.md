## Description

Les apps de productivité sont fragmentées — les utilisateurs jonglent entre des outils séparés pour les tâches, notes, calendrier, nutrition et musique. Haomirai consolide 10 modules fonctionnels dans une seule app Flutter cross-platform avec 44 écrans, partageant un seul design system, une couche d'authentification et un client API. Pas une todo-app tutoriel — une super-app production-grade.

## Description Technique

Module nutrition : 14 modèles Freezed, 32+ méthodes API, scan de code-barre, templates de régimes alimentaires, évaluations de santé, tarification géolocalisée. Système d'import de musique YouTube avec téléchargements en background, playlists et lecteur audio. Riverpod StateNotifier sur 15 providers, GoRouter avec redirects auth-aware, 25 modèles Freezed immuables, intercepteurs Dio pour JWT refresh.

## Description Fonctionnelle

Application mobile super-app avec gestion de tâches, notes, calendrier, suivi nutritionnel, musique et plus. Architecture Flutter complète démontrant la scalabilité de Dart sur des projets complexes.

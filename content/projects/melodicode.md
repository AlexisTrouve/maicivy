## Description

IDE desktop orchestré par IA, conçu comme alternative à Claude Code. Un coordinateur Claude Opus (1M context) gère les projets et délègue le travail à des agents workers Sonnet/Haiku autonomes. Tooling complet intégré : lecture, écriture, édition de fichiers, bash, grep, glob, git. Compression de contexte intelligente, détection de commandes dangereuses, mode autonome expérimental avec budget tokens et kill switch. Interface Flutter Desktop multi-projets avec chat, subchat pour suivre les agents en temps réel, planificateur de tâches ProjectMind intégré, et notifications sonores.

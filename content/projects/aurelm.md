## Description

Boîte à outils IA pour maîtres de jeu de JDR civilisation. Ingestion des tours via Discord, pipeline ML (extraction d'entités multi-civilisation via spaCy), génération automatique de wiki, et agent Claude (OpenClaw) pour requêtes et vérification de cohérence. 9 outils MCP, 59 tests ML, 24 tests d'intégration MCP, interface Flutter/Dart.

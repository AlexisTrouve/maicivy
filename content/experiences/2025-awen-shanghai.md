## Description

Déploiement et configuration de l'infrastructure technique complète pour la revente de tokens API IA (Anthropic/OpenAI) via un partenaire basé à Shanghai. Mission à distance depuis la Chine, marché hors-Chine.

## Description Technique

Mise en place et configuration d'une infrastructure multi-composants : proxy OpenAI-to-Anthropic pour compatibilité cross-provider, serveur de licences avec enforcement et détection de piratage, installateur desktop Electron (Windows/macOS) avec interface bilingue chinois/anglais, gestion de services système (Registry/launchd), accès mobile via QR code UPnP. Déploiement sur VPS multi-continents.

## Description Fonctionnelle

Infrastructure permettant la distribution de tokens API IA à des utilisateurs finaux non-techniques : installation guidée, activation de licence, gestion des sessions et accès depuis mobile. Support du marché chinois avec UI localisée (200+ clés i18n) et conformité aux contraintes réseau locales.
